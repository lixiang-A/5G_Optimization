# 参数灵敏度分析操作指南

这份文档用于直接执行。当前代码已经支持通过命令行传入 `alpha_u` 与 `beta_u/beta_e/beta_m`，因此**不需要手改脚本**，直接在项目根目录复制命令运行即可。

## 1. 实验目标

本次参数灵敏度分析只考察两类效用校准常数：

- `alpha_u`：URLLC 的截止前时延衰减系数
- `beta_u, beta_e, beta_m`：三类切片任务超时后的惩罚系数

本次**不做** `lambda_power / lambda_interference / lambda_fairness` 的灵敏度分析。

## 2. 建议实验范围

建议只做以下两组：

### 2.1 `alpha_u` 灵敏度

固定：

- `beta_u=5`
- `beta_e=3`
- `beta_m=1`

测试：

- `alpha_u = 0.90`
- `alpha_u = 0.93`
- `alpha_u = 0.95`
- `alpha_u = 0.97`

### 2.2 `beta` 灵敏度

固定：

- `alpha_u = 0.95`

测试三组惩罚系数：

- `(beta_u, beta_e, beta_m) = (4, 2, 1)`
- `(beta_u, beta_e, beta_m) = (5, 3, 1)`
- `(beta_u, beta_e, beta_m) = (6, 4, 2)`

## 3. 实验对象

本次优先做：

- **第二问**：必须做，作为主灵敏度实验
- **第三问**：要做，作为完整多站场景验证

不建议把第一问作为正文主灵敏度分析对象；若需要，可后续单独补成附录说明。

## 7. 第三问：`alpha_u` 灵敏度

说明：

- 第三问改 `alpha/beta` 后，需要**重新训练**，不能只评估旧模型。
- 为了控制成本，本轮统一固定 `seed=17`。
- 本轮统一沿用当前论文主结果设置：`total_timesteps=10000`，`eval_episodes=1`。

直接复制下面整段：

```bash
source .venv/bin/activate
cd /Users/liz/Desktop/5G_Optimization

for alpha in 0.90 0.93 0.95 0.97; do
  ./.venv/bin/python q3_sb3.py train-slice \
    --device cpu \
    --seed 17 \
    --alpha-u "$alpha" \
    --beta-u 5 --beta-e 3 --beta-m 1 \
    --total-timesteps 10000 \
    --eval-freq 1000 \
    --eval-episodes 1 \
    --model-out "outputs/sensitivity/q3_alpha/q3_slice_alpha_${alpha}.zip" \
    --metrics-out "outputs/sensitivity/q3_alpha/q3_slice_alpha_${alpha}.json" \
    --plot-out "outputs/sensitivity/q3_alpha/q3_slice_alpha_${alpha}.png"

  ./.venv/bin/python q3_sb3.py train-power \
    --device cpu \
    --seed 17 \
    --alpha-u "$alpha" \
    --beta-u 5 --beta-e 3 --beta-m 1 \
    --slice-mode model \
    --slice-model-in "outputs/sensitivity/q3_alpha/q3_slice_alpha_${alpha}.zip" \
    --total-timesteps 10000 \
    --eval-freq 1000 \
    --eval-episodes 1 \
    --model-out "outputs/sensitivity/q3_alpha/q3_power_alpha_${alpha}.zip" \
    --metrics-out "outputs/sensitivity/q3_alpha/q3_power_alpha_${alpha}.json" \
    --plot-out "outputs/sensitivity/q3_alpha/q3_power_alpha_${alpha}.png"

  ./.venv/bin/python q3_sb3.py evaluate \
    --seed 17 \
    --alpha-u "$alpha" \
    --beta-u 5 --beta-e 3 --beta-m 1 \
    --slice-mode model \
    --slice-model-in "outputs/sensitivity/q3_alpha/q3_slice_alpha_${alpha}.zip" \
    --power-model-in "outputs/sensitivity/q3_alpha/q3_power_alpha_${alpha}.zip" \
    --eval-episodes 1 \
    --metrics-out "outputs/sensitivity/q3_alpha/q3_eval_alpha_${alpha}.json"
done
```
