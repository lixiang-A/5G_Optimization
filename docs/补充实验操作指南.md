# Q3 补充实验操作指南

本指南用于补充 Q3（多基站干扰耦合）的基线对照和消融实验。所有命令均可在普通笔记本电脑上运行。

## 前置：拉取最新代码

```bash
cd 5G_Optimization          # 进入项目目录
git pull origin feat/project-setup
```

---

## 命令 1：uniform 非学习启发式基线（约 10 秒）

评估均匀 RB 分配 + 固定 30dBm 功率，无需训练。

```bash
python q3_sb3.py evaluate-uniform \
  --total-timesteps 64 --eval-episodes 2 \
  --metrics-out outputs/q3_sb3/uniform_baseline.json
```

输出文件：`outputs/q3_sb3/uniform_baseline.json`

---

## 命令 2：slice-only 消融实验（约 10 秒 × 3）

评估"仅切片层 + 固定功率"的效果，用于隔离功率层贡献。需要已有训练好的 slice 模型（仓库已包含）。

```bash
# seed=17（最佳展示 seed）
python q3_sb3.py evaluate-slice-only \
  --total-timesteps 64 --eval-episodes 2 \
  --slice-model-in outputs/q3_sb3/q3_slice_ppo_seed17_10k.zip \
  --fixed-power-dbm 30.0 \
  --metrics-out outputs/q3_sb3/slice_only_seed17.json

# seed=7
python q3_sb3.py evaluate-slice-only \
  --total-timesteps 64 --eval-episodes 2 \
  --slice-model-in outputs/q3_sb3/q3_slice_ppo_seed7_10k.zip \
  --fixed-power-dbm 30.0 \
  --metrics-out outputs/q3_sb3/slice_only_seed7.json

# seed=27
python q3_sb3.py evaluate-slice-only \
  --total-timesteps 64 --eval-episodes 2 \
  --slice-model-in outputs/q3_sb3/q3_slice_ppo_seed27_10k.zip \
  --fixed-power-dbm 30.0 \
  --metrics-out outputs/q3_sb3/slice_only_seed27.json
```

输出文件：`outputs/q3_sb3/slice_only_seed17.json`、`slice_only_seed7.json`、`slice_only_seed27.json`

---

## 命令 3：训练单层 joint PPO 基线（约 5-15 分钟）

训练一个非分层的单层 PPO，作为对照。联合动作空间 = 21 种 RB 划分 × 3 档功率 = 63 个复合动作/站。

```bash
# seed=17（推荐，对应最佳展示 seed）
python q3_sb3.py train-joint \
  --total-timesteps 10000 --seed 17 \
  --eval-freq 2000 --eval-episodes 2 \
  --model-out outputs/q3_sb3/q3_joint_ppo_seed17_10k.zip \
  --metrics-out outputs/q3_sb3/q3_joint_ppo_seed17_10k_metrics.json
```

输出文件：
- `outputs/q3_sb3/q3_joint_ppo_seed17_10k.zip`（模型）
- `outputs/q3_sb3/q3_joint_ppo_seed17_10k_metrics.json`（训练曲线）
- `outputs/q3_sb3/q3_joint_ppo_seed17_10k_curves.png`（收敛图）

---

## 命令 4：评估训练好的 joint PPO（约 10 秒）

```bash
python q3_sb3.py evaluate-joint \
  --total-timesteps 10000 --eval-episodes 2 \
  --joint-model-in outputs/q3_sb3/q3_joint_ppo_seed17_10k.zip \
  --metrics-out outputs/q3_sb3/q3_joint_eval_seed17_10k.json
```

输出文件：`outputs/q3_sb3/q3_joint_eval_seed17_10k.json`

---

## 命令 5（可选）：多 seed joint PPO

如果时间和算力允许，可以补充 seed=7 和 seed=27：

## 执行顺序建议

1. 先跑命令 1（uniform）→ 秒级，验证环境正常
2. 再跑命令 2（slice-only 消融，三个 seed）→ 秒级 × 3
3. 最后跑命令 3（train-joint）→ 唯一需要等几分钟的
4. 命令 3 结束后立刻跑命令 4（evaluate-joint）
5. 有时间再跑命令 5（多 seed）
